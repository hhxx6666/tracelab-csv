# TraceLab · 实验数据对比器

拖入两份 CSV，按同一个触发事件对齐实验记录，找出超差时段并导出可离线打开的 HTML 报告。CSV 由浏览器读取和计算。

**[打开在线演示](https://hhxx6666.github.io/tracelab-csv/)**

## 30 秒首发演示

1. 点击 **载入电机样例**。基准记录与新版记录分别在原始时间 **1.2125 s** 和 **1.860 s** 穿越启动指令阈值。图表把两次启动时刻都移到 **t = 0**。
2. 保持绝对容差 **±50 rpm**。新版转速在启动后短时过冲，对齐后的约 **0.583–1.366 s** 标为红色。区间持续 **0.782 s**，最大偏差约为 **+167.0 rpm**。
3. 点击 **导出 HTML 报告** 下载一份包含两张图、超差区间和输入参数的报告。将下载文件复制到另一台电脑也能直接打开。
4. 把 [基准样例 CSV](samples/motor-baseline.csv) 和 [新版样例 CSV](samples/motor-v2.csv) 分别拖到 A、B，可走一遍实际导入流程。填入容差 **50**，然后换成自己的记录。

两份样例为确定性生成的模拟数据。基准每 25 ms 采样一次，新版每 20 ms 采样一次。

## CSV 格式和触发设置

使用 UTF-8 CSV，第一行为唯一列名。支持逗号、分号和制表符分隔，以及带引号的字段。

```csv
time_s,start_cmd,speed_rpm
0.000,0,0
0.025,0,0
0.050,1,105
0.075,1,284
```

- 两份文件可以使用不同列名，也可以分别选择秒或毫秒。时间列必须严格递增，所选列须为有限数值。两条信号应使用相同的测量单位。每个文件最大 10 MiB。
- 在 **列映射与触发参数** 内选择两个文件的时间、触发与信号列。上升沿从阈值下方穿越到阈值或以上，下降沿反之。触发时间在线性插值后确定。可选第几次穿越，也可以任选 **首个采样点** 对齐。
- 对齐后只比较两条信号的重叠时段。按两条时间轴的采样时间并集进行线性插值，并求出偏差穿越容差边界的时刻。绝对偏差严格大于容差才计为超差，边界显示到毫秒。带符号偏差为 **新版 B − 基准 A**。

## 本地运行与部署

下载仓库并在现代浏览器里打开 `index.html`。应用由原生 HTML、CSS 和 JavaScript 编写，图表使用 Canvas。无需安装依赖或运行构建。

在自己的 GitHub 仓库中，进入 **Settings → Pages**，从 **Deploy from a branch** 发布 **main / (root)**。详见 [GitHub Pages 文档](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 测试

`assets/compare.js` 同时以 CommonJS 导出，可以直接在 Node.js 22 或更新版本上测试，无需安装依赖：

```sh
node --test
```

用例覆盖 CSV 解析、列推断、触发对齐、容差边界与超差区间的切分合并，并锁定上面那组演示数字。
