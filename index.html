使用指南

  1. 试用电机样例。 用启动指令的第一次上升沿对齐两次记录。新版转速在启动后短时过冲，红色标出超过 ±50 rpm 的时段。
  2. 拖入自己的 CSV。 分别拖到 A 和 B，也可以一次拖入两个文件。CSV 使用 UTF-8，首行为列名。时间必须严格递增，支持秒和毫秒。导入后填入绝对容差。
  3. 选择同一个事件。 展开「列映射与触发参数」，为两份文件选好时间、触发和测量信号列，再设置阈值和触发次数。没有触发列时，可选择从首个采样点对齐。
  4. 查看并导出。 绝对偏差大于容差时标红。点击「导出 HTML 报告」下载图表、参数和区间表，文件可离线打开。
